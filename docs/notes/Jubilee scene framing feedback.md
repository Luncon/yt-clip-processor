# Jubilee scene framing feedback

User observation during a Jubilee-style video run: split-screen crops work for
front-facing news interviews, but profile views can leave part of a speaker's
face outside a pane. Wide 16:9 shots occupy too little of the portrait canvas.

The current dual anchor is limited to exactly one half of the source width;
the current wide renderer fits the complete landscape frame with black bars.
The requested outcome is more room around each speaker in dual mode and a
larger centered view in wide mode. The current run has not yet been inspected.

See [improve-scene-framing](../../openspec/changes/improve-scene-framing/proposal.md)
for the agreed, testable behavior.
