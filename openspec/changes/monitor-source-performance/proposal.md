## Why

The clip processor accepts a video URL but has no way to discover which source videos are gaining traction. The pilot needs repeatable performance evidence before choosing a video to clip.

## What Changes

- Monitor recent YouTube uploads from Tucker Carlson, Candace Owens, Hasan Piker (HasanAbi), and Fox News.
- Store dated video statistics locally and report view growth between observations.
- Keep the source list editable and the monitor separate from media processing.

## Scope

This change covers source discovery and source performance only. Clip selection, TikTok analytics, scheduling, and posting remain later work. An API key is required for live polling.
